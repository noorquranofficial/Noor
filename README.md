# Noor Islamic

A static educational website for Quran study, selected Hadith, duas and related Islamic resources.

Website: https://noorquranofficial.github.io/Noor/

## Structure
- `index.html`: main interactive website
- `quran/`, `hadith/`, `duas/`: collections and detail pages
- `about/`, `contact/`, `privacy/`, `terms/`, `disclaimer/`, `sources/`: standalone information and policy pages
- `robots.txt` and `sitemap.xml`: search-engine crawl guidance
- `.github/workflows/static.yml`: GitHub Pages deployment workflow

## Deployment
The `main` branch is deployed to GitHub Pages by the Actions workflow on push.
